Política de Privacidade — Motivação Diária Publisher

Vigente desde 24 de setembro de 2026. Atualizada em 26 de setembro de 2026.

O Motivação Diária Publisher é uma ferramenta pessoal, executada apenas no computador do dono do canal do YouTube "Motivação Diária". Ela não é oferecida ao público e não tem outros usuários.

O que a ferramenta faz com a API do YouTube

Este app usa os YouTube API Services (Serviços de API do YouTube). Ao usá-lo, você concorda com os Termos de Serviço do YouTube.

A ferramenta usa os Serviços de API do YouTube (YouTube Data API v3) com uma única permissão (youtube.upload) para enviar vídeos curtos produzidos pelo próprio dono ao seu próprio canal, como privados e com data de publicação agendada. Ela não lê, não coleta e não exibe dados de outros usuários ou canais do YouTube.

Dados acessados e armazenados

  • Token de acesso OAuth — guardado somente no computador do dono do canal, no arquivo local credenciais/token.json. Serve apenas para enviar os vídeos ao canal do próprio dono.
  • ID de cada vídeo enviado — salvo localmente no registro de vídeos da ferramenta, para o dono acompanhar as próprias publicações (horário e status de cada envio).
  • A ferramenta não acessa nenhum outro dado da conta Google ou do YouTube.
  • Nenhum dado é enviado a servidores próprios ou de terceiros, vendido ou compartilhado. Não há cookies, análise de uso nem publicidade.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento nas configurações de segurança da conta Google: https://security.google.com/settings/security/permissions.

Eliminação de dados e prazo de retenção

  • Para apagar os dados, o dono apaga o arquivo credenciais/token.json e o registro de vídeos enviados no próprio computador. Não existe cópia em nenhum outro lugar.
  • Depois da revogação, o token deixa de funcionar e nenhum dado do YouTube ou da conta Google é mais acessado.
  • Retenção: o token fica guardado apenas enquanto a ferramenta estiver em uso e é apagado ao revogar o acesso ou ao deixar de usar a ferramenta. Os IDs dos vídeos ficam no registro local até o dono apagá-lo.
  • Pedidos de exclusão podem ser enviados para audiotimports@gmail.com e são atendidos em até 7 dias.

Termos e políticas do YouTube e do Google

Ao usar esta ferramenta, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Privacy Policy — Motivação Diária Publisher

Effective September 24, 2026. Updated September 26, 2026.

Motivação Diária Publisher is a personal tool that runs only on the computer of the owner of the "Motivação Diária" YouTube channel. It is not offered to the public and has no other users.

What the tool does with the YouTube API

This app uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service.

The tool uses YouTube API Services (YouTube Data API v3) with a single scope (youtube.upload) to upload short videos produced by the owner to the owner's own channel, as private videos with a scheduled publish time. It does not read, collect or display data from any other YouTube users or channels.

Data accessed and stored

  • OAuth access token — stored only on the channel owner's computer, in the local file credenciais/token.json. It is used only to upload videos to the owner's own channel.
  • ID of each uploaded video — saved locally in the tool's upload log so the owner can track their own uploads (time and status of each upload).
  • The tool does not access any other Google account or YouTube data.
  • No data is sent to our own or third-party servers, sold or shared. There are no cookies, analytics or ads.

How to revoke access

Access can be revoked at any time in the Google account security settings: https://security.google.com/settings/security/permissions.

Data deletion and retention

  • To delete the data, the owner deletes the file credenciais/token.json and the local upload log on their own computer. No copy exists anywhere else.
  • After access is revoked, the token stops working and no YouTube or Google account data is accessed anymore.
  • Retention: the token is kept only while the tool is in use and is deleted when access is revoked or the tool is no longer used. Video IDs stay in the local log until the owner deletes it.
  • Deletion requests can be sent to audiotimports@gmail.com and are handled within 7 days.

YouTube and Google terms

By using this tool, the YouTube Terms of Service and the Google Privacy Policy apply.
